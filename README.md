# 🐢 토끼와 거북이

> 느려도 끝까지, 같은 교실에서 함께 배우는 수업

**경계선 지능(느린 학습자) 학생**이 일반 학급 수업을 놓치지 않도록 돕는 웹 서비스입니다.
교사가 평소에 쓰는 수업 자료(PDF)와 수업 중 교사의 말을 AI가 **쉬운 문장**으로 바꿔 학생 화면에 실시간으로 보여 줍니다.
학생은 다른 친구들과 같은 교실, 같은 수업에 있으면서도 자기 속도로 수업을 따라갈 수 있습니다.

---

## 1. 왜 만들었나요

경계선 지능 학생은 지적장애에 해당하지 않아 특수교육 대상이 아닙니다. 그래서 대부분 **일반 학급에서 다른 학생과 같은 속도의 수업**을 듣습니다.
하지만 다음과 같은 어려움 때문에 수업을 따라가기 힘듭니다.

| 어려움 | 연구에서 보고된 내용 |
|---|---|
| **작업기억·처리속도가 낮음** | 경계선 지적 기능 초등학생 150명의 지능검사(K-WISC-IV) 결과, 작업기억 **80.32점**, 처리속도 **79.97점**으로 지표 가운데 가장 낮았습니다(평균 100점). 긴 문장을 끝까지 기억하며 읽거나, 선생님 말을 들으면서 바로 이해하기 어렵습니다. |
| **읽기 이해가 부족함** | 경계선 지적 기능 아동의 **50.9%가 읽기 평균에 못 미쳤고**, 15.6%는 학습지체 수준이었습니다. 또래보다 이야기 이해 점수도 뚜렷하게 낮았습니다. |
| **낱말의 확장된 뜻을 잘 모름** | 어휘 수준이 같은 아동과 비교해도, "기회를 잡다"처럼 **넓어진 뜻을 이해하는 데 특히 큰 어려움**을 보였습니다. 교과서에는 이런 말과 한자어가 많습니다. |
| **주의집중이 어려움** | 행동평가 척도에서 주의집중 문제가 **임상 범위**(지원이 필요한 수준)에 해당했습니다. |

선생님 한 명이 수업 중에 이 학생들을 따로 챙기기는 어렵습니다.
**토끼와 거북이**는 수업 흐름은 그대로 두고, 학생 한 명 한 명 옆에 "쉽게 풀어 주는 보조 선생님"을 붙여 주는 것을 목표로 합니다.

## 2. 주요 기능

### 👩‍🏫 교사

| 기능 | 설명 |
|---|---|
| **수업 자료를 쉬운 문장으로 변환** | PDF를 올리면 AI가 페이지마다 쉬운 문장, 어려운 낱말 풀이, 그림이 필요한 부분을 정리합니다. |
| **AI 그림 생성** | 과정·순서·관계처럼 글로만은 어려운 부분에 글자 없는 교육용 그림을 만듭니다. |
| **검토 후 공개** | AI가 만든 내용은 교사가 직접 고치고 **승인해야만** 학생에게 보입니다. 낱말을 새로 넣으면 그 페이지 맥락에 맞는 쉬운 뜻을 AI가 채워 줍니다. |
| **실시간 수업 화면** | 수업 화면에 들어가면 음성 인식이 켜집니다. 교사가 말하면 그 말이 지금 보고 있는 페이지에 쌓이고, 쉬운 자막으로 바뀌어 학생에게 전달됩니다. |
| **판서와 레이저 포인터** | 슬라이드 위에 펜·형광펜으로 쓰고 지울 수 있습니다(저장됨). 레이저 포인터는 학생 화면에 실시간으로 보입니다. 전체 화면을 지원합니다. |
| **확인 문제 자동 생성** | 수업이 끝나면 수업 자료와 실제 설명을 바탕으로 OX·3지선다 문제 5개 안팎을 만듭니다. |
| **과목·회차 관리** | 과목을 만들면 초대 코드가 생깁니다. 회차마다 번호·제목·날짜를 정하고 고칠 수 있습니다. |

### 🧒 학생

| 기능 | 설명 |
|---|---|
| **쉬운 문장으로 수업 보기** | 큰 슬라이드 옆에 쉬운 문장, 낱말 풀이, 그림을 함께 봅니다. |
| **선생님 설명 실시간 자막** | 선생님이 한 말이 쉬운 자막으로 바로 나타납니다. 잡담·출석 같은 말은 빠지고, "이제 ○○을 볼 거예요" 같은 흐름 안내는 구분해서 보여 줍니다. |
| **내 속도로 페이지 이동** | 페이지를 자유롭게 넘길 수 있고, "선생님은 지금 N쪽"과 **따라가기** 버튼으로 언제든 수업 위치로 돌아옵니다. |
| **어려운 낱말 풀이** | 페이지마다 교과 핵심 용어와 쉬운 뜻을 함께 보여 줍니다. |
| **나만의 판서** | 학생도 슬라이드 위에 필기할 수 있고, 다시 들어와도 남아 있습니다. |
| **집중 도우미** | 웹캠으로 고개를 돌리거나 자리를 비우거나 멍하니 있는 상태가 이어지면 "집중!" 알림을 띄웁니다. 영상은 학생 기기 안에서만 분석하고, 저장하거나 서버로 보내지 않습니다. |
| **확인 문제** | 수업이 끝나면 쉬운 문제를 풀고 바로 채점과 해설을 봅니다. |
| **수업 챗봇** | 그 회차 수업 내용을 근거로만 답하고, 근거 페이지를 함께 알려 줍니다. 수업과 무관하거나 수준을 넘는 질문은 정중하게 돌려보냅니다. 손을 들고 묻기 어려운 학생도 혼자 물어볼 수 있습니다. |

### 공통

- 교사·학생 계정 로그인, 프로필 사진·이름·비밀번호 수정
- 수업 일정 달력 (학교 학사 일정과 함께)
- **슈퍼스쿨 연동 구조**: 학교 플랫폼 슈퍼스쿨 계정으로 로그인하고 학사 일정을 받아오는 OAuth 흐름을 구현해 두었습니다. 슈퍼스쿨이 외부 API를 공개하지 않아 지금은 가짜(mock) 데이터로 동작하며, API를 받으면 설정만 바꿔 연결할 수 있습니다.
- 노트북과 태블릿(아이패드)에서 함께 사용 가능

## 3. 쉬운 문장으로 바꾸는 기준

학생 특성에 맞춰 AI에게 아래 규칙을 지키게 했습니다 ([app/ai/prompts.py](app/ai/prompts.py)).

| 기준 | 이유 |
|---|---|
| 한 문장은 **25자 안팎**, 한 문장에 **한 가지 내용만** | 작업기억이 약해 긴 문장은 끝까지 읽기 전에 앞부분을 잊습니다. |
| 단, **원인과 결과, 재료와 결과는 한 문장에** 둠 (원문 한 문장 → 쉬운 문장 1~2개) | 너무 잘게 쪼개면 내용 사이의 관계를 스스로 잇기 어렵습니다. |
| 어려운 한자어는 쉬운 말로 바꾸되, **교과 핵심 용어는 그대로 두고 뜻을 따로** 붙임 | 같은 반 친구들과 같은 용어로 수업을 듣고 시험을 봐야 합니다. |
| 모든 문장은 **"~해요"체** | 딱딱한 문체보다 거부감이 적습니다. |
| **"어렵죠?", "쉽죠?" 같은 말은 쓰지 않음** | 자존감을 다치게 하지 않기 위해서입니다. |
| **원문에 없는 사실은 덧붙이지 않음** | 수업 내용과 다른 것을 배우거나 혼란스러워지지 않게 합니다. |
| 실시간 자막에서 **잡담·출석·생활지도는 빼고**, 수업 흐름 안내는 남김 | 중요한 말과 아닌 말을 스스로 가려내기 어렵습니다. |

## 4. 사용 흐름

```
교사  과목 만들기(초대 코드) → 회차 추가(PDF) → AI 변환 → 검토·수정·그림 → 승인
      → 수업 시작(음성 인식, 판서, 레이저) → 수업 끝 → 확인 문제 만들기

학생  초대 코드로 과목 참여 → 승인된 회차 보기
      → 슬라이드 + 쉬운 문장 + 실시간 자막 → 확인 문제 · 챗봇
```

## 5. 기술 스택

| 구분 | 사용 기술 |
|---|---|
| 프론트엔드 | React 19, TypeScript, Vite, React Router, MediaPipe(집중 도우미), Web Speech API(음성 인식) |
| 백엔드 | Python 3.12+, FastAPI, WebSocket, SQLModel + SQLite, PyMuPDF(PDF 처리) |
| AI | 안뇽GPT API Gateway: 텍스트 `gemini-3.8-flash`, 이미지 `gemini-nano-banana-2.1` |
| 테스트 | pytest (173개, AI 호출 없이 실행) |

```
브라우저(교사) ──음성 인식 텍스트──▶ FastAPI ──▶ AI(쉬운 자막)
       ▲                            │  WebSocket
       └──────── 레이저·페이지 ───────┼──────────▶ 브라우저(학생)
                                     └── SQLite · 이미지 저장소
```

- 음성은 브라우저에서 글자로 바꾸고, **원본 음성은 저장하지 않습니다.**
- AI 키는 서버에만 두고 프론트엔드에는 보내지 않습니다.

## 6. 실행 방법

필요한 것: **Python 3.12 이상**, **Node.js 20 이상**

### ① 백엔드 (터미널 1)

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env              # JWT_SECRET을 아무 긴 문자열로 바꿔 주세요
.venv/bin/python -m scripts.seed  # 데모 계정·과목 만들기
.venv/bin/uvicorn app.main:app --port 8000
```

- 기본 설정(`MOCK_AI=true`, `MOCK_IMAGE=true`)에서는 **AI 키 없이** 정해진 예시 응답으로 모든 기능을 써 볼 수 있습니다.
- 실제 AI를 쓰려면 `.env`에 `AI_API_KEY`(안뇽GPT Gateway 키)를 넣고 `MOCK_AI=false`, `MOCK_IMAGE=false`로 바꾼 뒤 서버를 다시 켜세요.
- 확인: http://localhost:8000/health · API 문서: http://localhost:8000/docs

### ② 프론트엔드 (터미널 2)

```bash
cd frontend
npm install
cp .env.example .env.local
# .env.local에서 VITE_USE_MOCK=false 로 바꾸기 (백엔드에 연결)
npm run dev
```

브라우저에서 **http://localhost:5173** 을 엽니다.

> 백엔드 없이 화면만 보고 싶다면 `VITE_USE_MOCK=true`(기본값)로 두면 브라우저 안의 예시 데이터로 동작합니다.

### ③ 데모 계정 (비밀번호 모두 `pass1234`)

| 역할 | 아이디 |
|---|---|
| 교사 | `teacher1` |
| 학생 | `student1`, `student2`, `student3` |

과목 "과학"(초대 코드 `DEMO01`)과 학생 3명이 미리 등록되어 있습니다.

**실시간 수업 체험:** 한 창에서 `teacher1`로 로그인해 회차의 **수업 시작**을 누르고, 다른 창(또는 시크릿 창)에서 `student1`로 같은 회차에 들어가세요. 교사 화면에서 말하면 학생 화면에 쉬운 자막이 나타납니다.

> 음성 인식과 카메라는 **Chrome**에서, `localhost` 또는 https 주소로 열었을 때만 동작합니다.
> 태블릿 등 다른 기기에서 접속하는 방법은 [docs/BACKEND.md](docs/BACKEND.md#같은-wi-fi의-다른-기기태블릿휴대폰에서-접속하기)를 참고하세요.

## 7. 폴더 구조

```
app/            백엔드 (FastAPI)
  routers/        API (인증, 과목, 회차, 퀴즈, 챗봇, WebSocket, 판서, 달력, 슈퍼스쿨)
  services/       PDF 재구성, 실시간 자막, 퀴즈, 챗봇
  ai/             AI 연결, 프롬프트(쉬운 문장 규칙)
  superschool/    슈퍼스쿨 연동 (mock / OAuth)
frontend/       프론트엔드 (React)
  src/pages/      교사·학생 화면
  src/components/ 슬라이드 보드, 자막, 집중 도우미 등
scripts/        데모 데이터, 수업 리플레이
samples/        데모용 수업 자료 PDF
tests/          백엔드 테스트
docs/           상세 문서
```
